Étape 12 — RGPD simple

Respecter les données personnelles

Tu gères des données de personnes : la loi (RGPD) demande quelques garanties simples.

  1. Pouvoir SUPPRIMER une personne et toutes ses données (déjà prévu : suppression en cascade dans le schéma).
  2. Pouvoir EXPORTER les données d'une personne (son CSV à elle).
  3. Demander le CONSENTEMENT (case à cocher ; le champ existe déjà dans la table people).
  4. Noter une DURÉE de conservation (ex. archiver après X années sans contact).
  5. Tenir un journal minimal des actions importantes (création/suppression).
🤖 Prompt à copier-coller dans Codex (ou Claude Code)
Ajoute les fonctions RGPD : 1) sur la fiche personne, un bouton « Exporter ses données » (CSV de cette personne) ; 2) une case à cocher « consentement » avec date, enregistrée dans people.consent / consent_date ; 3) une table 'audit_log' simple qui enregistre les créations et suppressions de personnes (qui, quoi, quand). Explique comment tester.
Le RGPD en clair : ne garde que l'utile, dis aux gens ce que tu fais de leurs données, et permets-leur d'y accéder ou de les effacer.
