Une partie est déjà faite : l'analyse du besoin (Étape 1) et le schéma de la base de données (Étape 2). Tout est rangé dans un dépôt Git sur GitHub (un « dépôt » = un dossier de projet avec son historique).

Git & GitHub. Git est un carnet qui mémorise chaque modification du projet. GitHub est le site qui héberge ce carnet en ligne pour qu'on puisse le partager et le retrouver de n'importe où.

Le dépôt du projet

matthieubonamy/gestion_formation

Chemin A — Depuis ton téléphone / un navigateur (le plus simple pour commencer)

Tu peux tout lire et même faire avancer le projet sans rien installer, depuis un navigateur (téléphone ou PC) :

Astuce « coder depuis le navigateur ». Le projet a été démarré avec Claude Code sur le web (code.claude.com). Tu peux y ouvrir le même dépôt et demander à l'assistant de continuer une étape, même depuis un téléphone. C'est le moyen le plus accessible si tu n'as pas le PC sous la main. Alternative : GitHub Codespaces (un PC de développement dans le navigateur, gratuit quelques heures par mois).
⚠️ Sur téléphone, on peut lire, valider, écrire des textes et piloter l'assistant, mais taper du code à la main est inconfortable. Pour les étapes de code, garde un PC Windows à portée.

Chemin B — Depuis ton PC Windows (pour coder vraiment)

Tu installes 3 outils (détaillés dans la notice « Installer les outils ») puis tu clones le projet (= télécharger une copie liée au dépôt) :

cd Documents
git clone https://github.com/matthieubonamy/gestion_formation.git
cd gestion_formation
git checkout claude/training-management-pwa-5ibmi2

La dernière commande te place sur la branche de travail (la version en cours du projet).
