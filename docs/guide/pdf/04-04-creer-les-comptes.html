Créer ses comptes (gratuits)

GitHub, Supabase, Vercel
Notice 04 / 23  •  Guide perso pour Franck  •  juin 2026

Trois comptes gratuits suffisent pour tout le MVP. Utilise la même adresse email partout pour t'y retrouver, et un gestionnaire de mots de passe (ex. le trousseau du navigateur) pour les garder.

1) GitHub — héberge le code

2) Supabase — la base de données + les mots de passe de l'app

Supabase te donne d'un coup : une base de données (le classeur des données), l'authentification (le portier), le stockage de fichiers et des sauvegardes. Gratuit pour démarrer.
⚠️ Sur le plan gratuit, un projet Supabase est mis en pause après 1 semaine sans activité. Il suffit de le réactiver en un clic. Pour une vraie mise en production continue, on passera au plan payant (voir « Coûts »).

3) Vercel — met le site en ligne

Vercel publie l'application sur Internet à partir du code GitHub, automatiquement à chaque modification. C'est le créateur de Next.js.
⚠️ Le plan gratuit (Hobby) de Vercel est prévu pour un usage non-commercial. Pour une utilisation professionnelle réelle, il faut le plan Pro (~20 $/mois). Pour tester, le gratuit suffit. Détails et alternatives dans « Coûts ».
