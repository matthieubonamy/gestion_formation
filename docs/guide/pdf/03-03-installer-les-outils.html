Installer les outils (PC Windows)

Git, Node.js, VS Code — avec l'alternative téléphone/cloud
Notice 03 / 22  •  Guide perso pour Franck  •  juin 2026

Pour coder sur Windows, on installe 3 logiciels gratuits. Fais-les dans l'ordre.

1) Node.js (le moteur qui fait tourner l'application)

Node.js permet d'exécuter du code JavaScript sur ton ordinateur. Il vient avec npm, l'outil qui télécharge les briques toutes faites dont le projet a besoin.
node --version
npm --version

Si deux numéros s'affichent (ex. v22.x et 10.x), c'est bon ✅.

2) Git (le carnet de versions)

git --version

3) VS Code (l'éditeur où on écrit le code)

VS Code est un traitement de texte spécialisé pour le code : couleurs, suggestions, terminal intégré. Gratuit, fait par Microsoft.
⚠️ Si une commande « n'est pas reconnue », ferme et rouvre l'Invite de commandes : les nouveaux logiciels ne sont visibles qu'après redémarrage du terminal.
