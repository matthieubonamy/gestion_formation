Créer tes 3 comptes (clic par clic)

GitHub, Supabase, Vercel — tout est gratuit pour démarrer
Notice 03 / 24  •  Guide perso pour Franck  •  juin 2026

Trois comptes suffisent. Conseil : utilise la même adresse email partout, et laisse ton navigateur enregistrer les mots de passe.

Compte 1 — GitHub (héberge le code)

  1. Va sur https://github.com/signup.
  2. Saisis ton email, clique Continue.
  3. Choisis un mot de passe (note-le), clique Continue.
  4. Choisis un nom d'utilisateur (ex. franck-formation), clique Continue.
  5. Résous le petit puzzle de vérification, puis clique Create account.
  6. GitHub envoie un code par email : ouvre ta boîte mail, recopie le code dans GitHub.
  7. Aux questions « how many people / student / interests », tu peux cliquer Skip en bas. Choisis le plan Free.
✅ Vérifie : Tu arrives sur ton tableau de bord GitHub (page d'accueil avec « Dashboard »). Ton compte est créé ✅.

Sécurité (important) : active la double authentification.

  1. Va sur https://github.com/settings/security.
  2. Clique Enable two-factor authentication et suis les indications (le plus simple : une appli type « Authy » ou « Google Authenticator » sur ton téléphone).
Pour reprendre le projet existant, Matthieu devra t'ajouter au dépôt (il fait ça en 2 clics depuis ses réglages). Envoie-lui simplement ton nom d'utilisateur GitHub. Détails sur la page « Récupérer le travail ».

Compte 2 — Supabase (base de données + mots de passe de l'app)

Supabase te donne d'un coup : la base de données (le grand classeur), l'authentification (le portier), le stockage et les sauvegardes. Gratuit pour démarrer.
  1. Va sur https://supabase.com et clique Start your project (en haut à droite).
  2. Clique Continue with GitHub (le plus simple, ça réutilise ton compte GitHub). Autorise en cliquant Authorize.
  3. Tu arrives sur le tableau de bord Supabase. Clique New project.
  4. Si on te demande de créer une Organization : donne un nom (ex. le nom de ton organisme), choisis le type Personal et le plan Free, clique Create organization.
  5. Pour le projet : Name = gestion-formation. Database Password = clique « Generate a password » et copie-le précieusement (colle-le dans tes notes). Region = choisis Central EU (Frankfurt) ou West EU (Paris) — proche de toi.
  6. Clique Create new project. Patiente 1 à 2 minutes (Supabase prépare ta base).
✅ Vérifie : Tu vois le tableau de bord du projet avec un menu à gauche (Table Editor, SQL Editor, Authentication…). C'est prêt ✅.
⚠️ Sur le plan gratuit, un projet est mis en pause après 1 semaine sans activité. On le réactive en 1 clic (bouton « Restore »). Pour une mise en service continue, on passera au plan payant — à voir avec ton employeur (page « Coûts »).

Compte 3 — Vercel (met l'app en ligne)

Vercel publie l'application sur Internet à partir du code GitHub, tout seul à chaque modification.
  1. Va sur https://vercel.com/signup.
  2. Clique Continue with GitHub, puis Authorize Vercel.
  3. Choisis le plan Hobby (gratuit) pour l'instant. Renseigne un nom si demandé, clique Continue.
✅ Vérifie : Tu arrives sur le tableau de bord Vercel (vide pour l'instant, c'est normal). Compte prêt ✅.
⚠️ Le plan gratuit (Hobby) de Vercel est prévu pour un usage non-commercial : parfait pour tester et faire une démo. Pour une utilisation pro réelle, il faudra le plan Pro — décision à prendre avec ton employeur (page « Coûts »).
💬 Un mot, Franck

Voilà, tu as tes 3 clés d'entrée. Garde bien tous les mots de passe au même endroit (le trousseau de ton navigateur fait très bien le job). Si une étape coince — un bouton qui ne porte pas exactement le même nom, par exemple —, ne panique pas : les sites changent un peu leurs libellés, mais l'intention reste la même. Au moindre doute, demande-moi.
