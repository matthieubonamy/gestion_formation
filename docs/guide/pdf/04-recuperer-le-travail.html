Récupérer le travail déjà fait

Depuis le téléphone/navigateur OU depuis ton PC — pas à pas
Notice 04 / 24  •  Guide perso pour Franck  •  juin 2026

Une partie est déjà faite : l'analyse du besoin (Étape 1) et le schéma de base de données (Étape 2). Tout est rangé dans un dépôt Git sur GitHub.

Dépôt (repo). Un dossier de projet avec tout son historique, hébergé sur GitHub. Le nôtre : matthieubonamy/gestion_formation, branche claude/training-management-pwa-5ibmi2.

Chemin A — Sans rien installer (téléphone ou PC)

  1. Crée ton compte GitHub (page précédente).
  2. Envoie ton nom d'utilisateur GitHub à Matthieu et demande-lui de t'ajouter au dépôt.
  3. Matthieu, lui, va sur Settings → Collaborators du dépôt, clique Add people, colle ton nom d'utilisateur, et t'invite.
  4. Tu reçois un email d'invitation : clique Accept invitation.
  5. Tu peux maintenant ouvrir le dépôt dans le navigateur et lire les fichiers (dossiers docs/ et db/).
✅ Vérifie : Tu vois la liste des fichiers du projet sur github.com → tu as bien accès ✅.
Coder depuis le navigateur ? Le projet a été démarré avec Claude Code sur le web (code.claude.com). Tu peux y ouvrir le même dépôt et demander à l'assistant de continuer une étape, même depuis un téléphone. Autre option : GitHub Codespaces (un PC de dev dans le navigateur, gratuit ~60 h/mois).
⚠️ Sur téléphone, on lit et on pilote l'assistant, mais taper du code à la main est inconfortable. Pour coder vraiment, passe au Chemin B.

Chemin B — Sur ton PC Windows (pour coder)

  1. Ouvre l'Invite de commandes (menu Démarrer → tape cmd).
  2. Place-toi dans ton dossier Documents :
cd Documents
  1. Télécharge une copie du projet (= « cloner ») :
git clone https://github.com/matthieubonamy/gestion_formation.git
  1. Entre dans le dossier et place-toi sur la branche de travail :
cd gestion_formation
git checkout claude/training-management-pwa-5ibmi2
✅ Vérifie : Tape dir : tu dois voir les dossiers docs et db. Tu as bien le projet ✅.
Au premier git clone, GitHub peut te demander de te connecter : une fenêtre s'ouvre, clique « Sign in with your browser » et connecte-toi avec ton compte GitHub.

Variante : tout recréer de zéro (pour apprendre)

Si tu préfères tout reconstruire toi-même, tu n'as pas besoin de cloner : suis simplement les pages des Étapes 1 à 15 dans l'ordre, en repartant d'un dossier vide. Les fichiers déjà faits (docs/ et db/schema.sql) te serviront de modèle.
