Glossaire express

MotTraduction simple
FrontendCe qu'on voit (écrans, boutons)
BackendLe cerveau caché (règles, enregistrement)
Base de donnéesLe grand classeur des données
Repo / dépôtLe dossier du projet avec son historique

CloneTélécharger une copie du projet liée au dépôt
DéployerMettre l'app en ligne
Variable d'environnementUn réglage secret (clé) rangé hors du code
LocalhostTon ordinateur, l'app tourne juste pour toi

Problèmes fréquents et solutions

SymptômeCause probable → Solution
« command not found » / « n'est pas reconnu »Logiciel pas installé ou terminal pas redémarré → ferme et rouvre le terminal, revérifie l'installation.
L'app ne démarre pas (npm run dev échoue)Dépendances manquantes → lance npm install puis réessaie.
Page blanche / erreur SupabaseClés .env.local manquantes ou fausses → recopie-les depuis Supabase (Settings → API).
« Invalid login credentials »Mauvais email/mot de passe, ou compte admin pas créé dans Supabase → vérifie Authentication.
Le projet Supabase est « paused »Plan gratuit en pause après 1 semaine → clique « Restore » dans le tableau de bord Supabase.
Le déploiement Vercel échoueVariables d'environnement oubliées → ajoute-les dans Vercel → Settings → Environment Variables, puis redeploy.
Règle de dépannage du débutant : lis le message d'erreur en entier (il dit souvent quoi faire), copie-le dans un moteur de recherche, ou colle-le à l'assistant Claude Code en demandant « explique-moi cette erreur simplement ».

Où trouver de l'aide

  • La doc Supabase (supabase.com/docs) et Vercel (vercel.com/docs).
  • Claude Code sur le web : ouvre le dépôt et décris ton blocage.
  • Reprends la notice de l'étape concernée, étape par étape.
