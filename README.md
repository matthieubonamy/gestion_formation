# 📚 Gestion de formations — PWA

Application web (PWA) pour gérer une activité de formation : personnes
(prospects/clients), formations, inscriptions, suivi des paiements, relances
(mini-CRM), tableau de bord et export CSV.

**Stack :** Next.js + TypeScript · Supabase (base de données + auth) · Vercel (hébergement).
